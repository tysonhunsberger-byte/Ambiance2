## Playing Tips

### Basic Playing
1. **Press key** → Note starts (note-on)
2. **Release key** → Note stops (note-off)
3. **Hold key** → Note sustains
4. **Velocity slider** → Adjusts note loudness

### Advanced Techniques

#### Chords
Press multiple keys simultaneously:
- **C Major:** Z + C + N (C3 + E3 + G3)
- **G Major:** B + M + X (G3 + B3 + D3)
- **A Minor:** N + Z + C (A3 + C3 + E3)

#### Scales
Play in sequence:
- **C Major Scale:** Z → X → C → V → B → N → M → , (C3-C4)
- **Chromatic:** Z → S → X → D → C → V → G → B → H → N → J → M

#### Arpeggios
Play chord notes separately:
- **C Major Arp:** Z → C → N → , (C3 → E3 → G3 → C4)
- **Quick succession:** Hold each note briefly then release

#### Glissando (Sweep)
1. Click and **hold** mouse on a key
2. **Drag** mouse across other keys
3. Notes change automatically
4. **Release** to stop

## Keyboard Shortcuts

### Application Controls
- **Mouse Click** → Play single note
- **Mouse Drag** → Play glissando
- **Computer Keys** → Play notes (see table above)
- **Velocity Slider** → Adjust dynamics (0-127)
- **Octave Spinner** → Change octave (not yet implemented for typing)

### Focus Required
⚠️ **Important:** The Plugin Rack widget must have keyboard focus for typing to work!

**To ensure focus:**
1. Click anywhere in the Plugin Rack area
2. Or click on the keyboard widget
3. Blue outline appears (Qt focus indicator)

## Troubleshooting

### Keys Not Responding

**Problem:** Typing doesn't play notes

**Solutions:**
1. ✅ Click on Plugin Rack widget to give it focus
2. ✅ Ensure keyboard widget is visible (requires instrument plugin loaded)
3. ✅ Check Carla host status (must be "Carla ready")
4. ✅ Verify plugin is loaded and is an instrument
5. ✅ Check console log for MIDI errors

### Wrong Notes Playing

**Problem:** Key plays different note than expected

**Solution:**
- Verify keyboard layout matches your system (US keyboard assumed)
- Some international keyboards may have different key positions

### Stuck Notes

**Problem:** Note keeps playing after releasing key

**Solutions:**
1. ✅ Press and release the key again
2. ✅ Click "Unload" and reload plugin
3. ✅ Auto-repeat is disabled, but OS issues can cause this
4. ✅ Check if Carla backend is responsive

### Latency Issues

**Problem:** Delay between key press and sound

**Diagnosis:**
- **<10ms:** Normal (imperceptible)
- **10-50ms:** Acceptable for most playing
- **50-100ms:** Noticeable delay
- **>100ms:** Problematic

**Solutions:**
1. ✅ Already optimized (direct note-on/off, no timers)
2. ✅ Check audio driver settings in Carla
3. ✅ Use ASIO driver for lowest latency (requires ASIO4ALL)
4. ✅ Close other audio applications

## Practice Exercises

### Exercise 1: Scale Practice
Play C major scale up and down:
```
Up:   Z X C V B N M ,
Down: , M N B V C X Z
```

### Exercise 2: Finger Independence
Alternate between white and black keys:
```
Z S X D C V G B H N J M
```

### Exercise 3: Chord Building
Build major chords from each white key:
```
C Major:  Z + C + N
D Major:  X + ? + ?  (practice finding the notes)
E Major:  C + ? + ?
etc.
```

### Exercise 4: Mouse Glissando
1. Click and hold on **Z** (C3)
2. Drag smoothly to **,** (C4)
3. Try to hear each note clearly
4. Practice speed control
